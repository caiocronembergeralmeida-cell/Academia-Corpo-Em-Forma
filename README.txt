ACADEMIA CORPO EM FORMA — APP/PROTÓTIPO WEB

Arquivos:
- index.html: aplicativo completo com design, cadastro, planos e agenda.
- academia1.jpg, academia2.jpg, academia3.jpg: fotos enviadas para o projeto.

Como usar:
1. Extraia o arquivo ZIP.
2. Abra o index.html no navegador.
3. O cadastro e os treinos da agenda são demonstrativos e ficam salvos no navegador usando localStorage.

Observação:
Este é um protótipo front-end. Para cadastro real, login, pagamentos e banco de dados seria necessário conectar um backend.
